# 做一件大事！
## 这是什么
这是一本教材，依据《深入理解计算机系统》第三版改写。现在还不完整，我将用一年左右的时间完善这个仓库。
## 为什么要这么做
在学习这门课程（ICS）的时候，被这本教材折磨了很久。作者很努力想把知识讲解清楚，但是却并不适合一个初出茅庐的本科学生从 0 开始学习。你需要花很多时间理解一些明明后面会详细讲解、但是前面却要出现的概念。
## 我希望写成什么样
在我自己学习的过程中，我尝试用各式各样的 AI 来辅助我阅读这本教材。但是，囿于自己的能力，我被 ChatGPT 的防御性描述、Deepseek 的一句重点之类的贫乏而死寂的语言折磨到头晕脑胀却依旧很难理解。因此，我相信，有些东西还是需要人力完成。因此，我将对这各仓库中的每个文字符号负责到底。用真正的“人话”来讲解这些知识。

## 致谢
等这个仓库完成了再写吧。
